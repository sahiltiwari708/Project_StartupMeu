# StartupMeu - MERN Stack Web Application

## Project Description
StartupMeu is a full-stack web application built using the MERN stack (MongoDB, Express.js, React with Vite, Node.js). The application features a clean architecture with separate Frontend and Backend directories.

---

## Key Features
- **Frontend**: Responsive user interface built with React, Vite, and Tailwind CSS.
- **Backend**: RESTful API server created using Node.js and Express.js.
- **Database**: Cloud MongoDB Atlas integration for seamless data storage.
- **Environment Management**: Secure configuration using `.env` environment variables.

---

## Technologies Used
- **Frontend**: React.js, Vite, Tailwind CSS, JavaScript/TypeScript
- **Backend**: Node.js, Express.js, Cors, dotenv
- **Database**: MongoDB (MongoDB Atlas)
- **Version Control & AI Tools**: Git, GitHub, Code0 AI Terminal Assistant
